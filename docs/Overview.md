# Deepfake Toolkit Overview

This page gives a compact tour of the moving parts so you can form a mental model before digging into the code.

## High-Level Flow

```
Hugging Face SID_Set → SIDDatasetManager → Transforms → Trainer → Metrics/Checkpoints
                                                ↓
                                           Visualisations
```

1. **Configuration**  
   `ConfigLoader` merges `src/deepfake/config/default.yaml` with any override (for example `configs/quickstart-classification.yaml`). It also auto-selects the device and populates timestamped output paths.

2. **Data**  
   `SIDDatasetManager` (in `src/deepfake/data/dataset_manager.py`) pulls splits from Hugging Face, optionally filtering for tampered samples.  
   `SIDClassificationDataset` (in `src/deepfake/data/dataset.py`) converts records into tensors and applies the transform pipelines built by `utils/augmentation_factory.py`.

3. **Training / Evaluation**  
   - Classification lives in `src/deepfake/classification/train.py` and `evaluate.py`.  
   - Segmentation lives in `src/deepfake/segmentation/train.py` and `evaluate.py`.  
   Trainers expect a logger, metrics tracker, and checkpoint manager; they emit history JSON plus plots in the run directory.

4. **Utilities**  
   Shared helpers live under `src/deepfake/utils/`: logging (`logger.py`), configurability (`config_loader.py`), metrics (`training_metrics_tracker.py`, `evaluation_metrics_tracker.py`), and checkpointing (`checkpoint_manager.py`). Plots are generated by `src/deepfake/visualization/`.

5. **CLI vs. Notebook APIs**  
   The CLI (`src/deepfake/cli.py`) wires everything for automation. If you prefer an interactive path, import the new `deepfake.pipelines` module or run the `notebooks/quickstart_classification.ipynb` notebook to execute a minimal end-to-end training loop.


## Stepwise Helpers

Import `deepfake.pipelines` and chain the small functions:

1. `cfg = pipelines.load_config(...)`

2. `pipelines.seed_everything(cfg)`

3. `runtime = pipelines.init_training_runtime(cfg, "classification-demo")`

4. `trainer = pipelines.build_classification_trainer(cfg, runtime)`

5. `pipelines.run_training(trainer)`

6. `pipelines.summarise_training(cfg, runtime)` and `pipelines.collect_evaluation(cfg)` after running the evaluators.


The one-shot helpers (`train_classification`, `evaluate_classification`, etc.) still exist when you want a single call, but the stepwise surface is easier to follow in notebooks or tutorials.

## Suggested Starting Points

- `configs/quickstart-classification.yaml` – lowest-friction config tuned for small CPU runs.  
- `src/deepfake/pipelines.py` – simple `train_classification()` / `train_segmentation()` convenience wrappers.  
- `notebooks/quickstart_classification.ipynb` – hands-on walkthrough for a single experiment.

With these pieces you can explore the project without reading every utility file up front. When you need deeper control, drop back into the trainer and data modules knowing how they fit together.
